## 1. 人物技能系统（已确定，覆盖旧定义）

仅使用以下**四大类、12项技能**，不得新增、拆分或改名。

| 类别 | 技能 | 详细功能 |
| --- | --- | --- |
| 航海探索 | **导航** | 更容易控制船帆和船舵；航行更稳定；在相同风速条件下提高航速。 |
| 航海探索 | **视野** | 决定航行时的实时观察范围，并参与计算黑雾探索揭开半径。 |
| 航海探索 | **后勤** | 降低航行过程中的水、食品消耗速度。 |

| 制造工艺 | **配方** | 提高获得原料（R）→加工品（M）、加工品（M）→成品（C）配方的机会。 |

| 海上战斗 | **近战** | 提升近战（含登船战）的攻击力。 |
| 海上战斗 | **防御** | 提升近战防御力与海战中船只的防御力。 |

### 1.1 与旧版的对应

- 旧技能名 **“补给” → “后勤”**；旧技能名 **“工艺” → “效率”**。
- “补给”“工艺”依然可在物资补给、制造工艺等普通叙述中使用，但**不再是技能名**。
- 原“工艺”技能20级上限由“效率”继承（除非后续另行修订）；其他技能成长曲线依既有数据配置。
- 对已存在的技能ID、存档、UI文本、多语言字符串及伙伴数据执行兼容迁移；不得导致旧存档技能丢失。

### 1.2 计算与平衡原则

- **导航**：对船只的帆、舵操控稳定性和相同风速下速度提供加成；风向、船型等原有物理因素仍然生效。具体数值配置化。
- **视野**：实际视野由船只大小与视野技能等级决定；相关基准值、成长加成及黑雾探索系数全部放在数据文件中。
- **后勤**：按既有船员人数与每日耗水、耗粮基础值计算，再应用技能节约效果；资源消耗不能为负。
- **议价**：作用于玩家交易的结算价，而不是直接改写城市的全局行情；需要折扣上限和套利保护。
- **情报**：等级影响可获知信息的范围、内容及精度。
- **声望**：作用于交涉和城市产业建设成本，不改变商品基础价格。
- **配方**：改变配方获得概率，不直接改变商品制造耗时和品质。
- **效率**：缩短制造时间，不直接改变原料消耗或品质；时间减免应设置合理下限。
- **品质**：提高高品质产出的概率，但必须保留既有S、1、2、3、4、5等级，以及“成品品质不得优于允许的原料上限”等已有约束。
- **炮术 / 近战 / 防御**：分别进入海战火炮攻击、近战攻击以及近战/船体防御计算；加成和叠加上限由外部数据配置。

## 2. 黑雾探索与视野（已确定）

### 2.1 三场景共享永久探索进度

- **SailingScene**（手动航海）、**WorldMapScene**（世界地图）、**AutoSailingScene**（自动航行地图）显示相同的永久探索黑雾范围。
- 玩家此前从未航行探索的海域被黑色迷雾遮盖；玩家船只实际行经时，按探索半径沿途逐步揭开迷雾。
- 已揭开的海域永久保留探索状态；切换场景、离开海域、时间推移均不会恢复黑雾，存档读档后也应保留。
- 探索路径连续揭雾：快速移动不得留下不合理的断裂空档。

### 2.2 实时观察 ≠ 永久揭雾

- **实时视野半径**由船只大小、当前适用的“视野”技能等级共同计算；具体公式及数值配置化。
- **永久揭雾半径 = 实时视野半径 × 可配置的揭雾系数**。系数可为1.0，也可稍大于1.0（视觉上比视野大一圈）。
- 已探索区域的地形保持可见，但**其他船只、海怪、漂流物和动态事件只在当前船只实时视野内显示**。
- 因此不能通过已揭雾地图持续追踪远处的移动目标。

### 2.3 城市解锁陆地黑雾

- 船只无法航行的内陆区域主要通过**解锁城市**揭开。
- **每座城市预先配置一个多边形揭雾区域**，而非以城市为中心的圆形；多边形**主要覆盖陆地**，可按地形包含少量近岸区域。
- 解锁城市后，该多边形范围内的可视黑雾永久揭开；不同城市区域可重叠。
- **城市多边形揭开的海面不自动视为船只已经探索过的可通航海路**。地图显示取海域揭雾与城市揭雾的并集，但自动航行资格仍依据真实海上探索数据判定。

### 2.4 黑雾视觉表现

- 黑雾边界采用云雾质感、柔和羽化和自然透明度渐变，不采用硬方格边缘。
- 航行时黑雾可以渐进消散，然而实际探索判定必须来自精确坐标数据，不取决于视觉透明度。
- **待定美术方案**：①黑雾内隐约可见大陆/海岸轮廓；②完全隐藏地形。暂不将其中任何一项视为定案。

### 2.5 建议数据分离

- `SeaExploredArea`：真实航行探索过的海域，持久化；作为自动航线许可的依据。
- `CityRevealedArea`：城市解锁后揭开的预定义多边形，持久化；主要负责陆地及地图视觉。
- `CurrentVision`：当前船只位置、船型、视野技能及当下可见范围；可实时重算。
- `FogVisualState`：贴图、过渡效果及渲染缓存；不替代探索数据。

这些名称是**概念字段建议**，不是要求生成代码或锁定技术实现。

## 3. 自动航线的解锁条件（已确定）

**只有当起点与终点城市都已解锁，且两城之间存在一条完整已由手动航行探索、可通航的海路时，才允许建立自动航线。**

1. 发现或解锁两座城市，**不等于**自动解锁两城航线。
2. 整条自动航路必须位于实际航行已探索的海域；不得穿越任何未知黑雾区域，也不得穿越陆地和其他不可通航障碍。
3. 如两城的直线路段经过黑雾，但存在绕开黑雾的完整已探索可通航路线，则**允许绕行并建立自动航线**。
4. 探索区域可由多次手动航行连接形成；无需曾经一次性从起点完整驶到终点。
5. 如果不存在完整已探索路径，则提示玩家需要继续手动探索。
6. 城市多边形揭雾不能替代海域探索，也不能误解锁自动航线。
7. 自动航行本身是否进一步揭开新的黑雾仍为**待定**；当前不把自动航行作为主动探索未知海域的途径。

**设计目标**：手动航海负责未知探索，自动航行负责已开辟路线的经营与贸易。

- 原版12人作为基本人物构思保留，扩充到**18名候选伙伴**。
- 每人拥有**1项主要技能 + 2项辅助技能**，全部取自第1章的12项正式技能；职业身份或岗位不构成额外技能。
- 继续采用六种岗位：**导航探索、贸易情报、制造工艺、战斗护卫、船务后勤、外交管理**。岗位不是技能名。

### 4.3 人物简介及招募事件

**01 阿尔瓦罗·科斯塔**：曾随远洋船队经历恶劣风浪，信任海况和星空甚于旧海图。性格冷静、行事谨慎。**《遗失的航海日志》**：找回印度洋海流记录，获得其信任。

**02 纳西尔·伊本·哈迪**：来自学者家庭，迷恋星盘与海岸地形，善于察觉远方异常；不爱争执。**《星盘上的秘密》**：协助寻回一件天文仪器。

**03 沈若澜**：读遍家中地理典籍，渴望亲眼记录海外世界；观察细致、好奇心强。**《未完成的海图》**：探明一段未知海岸。

**04 萨米尔·汗**：管理过印度洋商队的淡水、粮食与靠港补给；务实而厌恶浪费。**《最后三桶淡水》**：救助缺水船队。

**05 伊莎贝拉·孔蒂**：成长于威尼斯商馆，擅长从谈判用词判断真正的供需；优雅且果断。**《威尼斯的契约》**：解决货物合同纠纷。

**06 露西亚·瓦尔加斯**：长期处理贸易许可与关税争议，深知信誉比一次利润更重要。**《被拒绝的通行证》**：帮助商人恢复贸易许可。

**07 哈桑·巴希尔**：穿梭黑海与地中海的情报商人，善于拼合传闻背后的商机。**《消失的香料船》**：追查失踪货船及商业骗局。

**08 让·马尔尚**：年轻时因误判货物价值而破产，此后特别注重品质鉴定与风险核算。**《真假宝石》**：追回遭替换的贵重货物。

**09 玛丽亚·德·索萨**：熟悉多个商团的习俗与合作方式，主张守信贸易。**《三封不同的信》**：化解跨商团误会。

**10 马特奥·费雷蒂**：威尼斯玻璃工匠，苛求火候与原料比例，希望制作传世精品。**《破碎的玻璃杯》**：寻获稀有材料并恢复失传工序。

**11 莱拉·法鲁克**：从家传文献中研究草药、香料及配方，善于辨别相似材料。**《古药方的最后一页》**：寻找缺失的材料或文献。

**12 陈远舟**：精于商船木作和船体结构，坚信好船需要经得起风浪。**《老船匠的考验》**：寻找木材并修复旧船。

**13 卡塔琳娜·范德梅尔**：曾管理家族工坊，熟知检验工序，希望建立独立品牌。**《工坊的印记》**：平息冒牌优质商品引发的信誉危机。

**14 梅芙·奥罗克**：出身爱尔兰海上家族，面对危险先保护船员，勇敢但固执。**《不愿投降的船长》**：帮助商船击退袭击者。

**15 艾米莉亚·里德**：擅长火炮维护与判断炮击时机，性格直率、对船员忠诚。**《最后一枚炮弹》**：帮助缺乏弹药的商船脱险。

**16 迪奥戈·阿尔梅达**：曾任护航队长，熟悉登船战，外表散漫却看重责任。**《酒馆里的决斗》**：调查护航失败背后的真相。

**17 奥斯曼·雷伊斯**：经历地中海舰队作战，注重队形与炮兵纪律。**《被遗弃的炮舰》**：调查战后弃置的舰船。

**18 格蕾娜·伯克**：虚构的爱尔兰海上女领袖，人物气质参考16世纪海上女王传说，但**不是**1700年仍在世的真实格蕾丝·奥马利。**《海上女王的挑战》**：完成高难度航行与海上对抗试炼。

**检查结论**：18人，四大类别全部覆盖；12项正式技能全部至少有一人以其为主要技能；没有独立的“造船”“药剂”“外交”“测绘”技能。

### 4.5 伙伴数据与成长

- 伙伴配置包含人物ID、多语言名称、文化背景、简介、岗位、招募地点、初始等级、主副技能、信赖、专属事件ID、招募状态等。
- 招募与个人事件可通过信赖等级解锁后续情节；专长阶段仍采用原讨论的“基础→专业→传奇”，但仅强化既有技能，不创造额外技能。
- 伙伴技能效果受到岗位、叠加规则和上限约束，不能形成无限折扣或无成本套利。
- 原伙伴效果中“减少远航消耗”归属**后勤**；“减少生产时间”归属**效率**；其余按当前技能定义重新核对。

## 5. 事件系统（继承原文档，并与1023功能衔接）

### 5.1 可插拔的事件框架

保留原方案：事件系统与城市、贸易、生产、航海、战斗系统解耦，事件通过配置表达触发条件和结果，而不是硬编码在某个场景中。

每条事件应能够描述：`eventId`、`trigger`、`prerequisites`、`priority`、`oneShotOrRepeat`、`cooldown`、`dialogue`、`choices`、`conditions`、`effects`、`nextEvent`。这些是设计字段名称，不代表本阶段提交代码。

事件监听来源包括进入城市、完成交易、生产完成、发现航线、战斗结束、伙伴交谈等；每次触发须判定前置条件、去重、冷却和分支后果。

### 5.2 原有主线结构保留

- **第一章《一张旧海图》**：取得家园产业设施及首条贸易航线。
- **第二章《诸港的契约》**：扩展跨城市产业园、原料→加工品→成品的供应链，招募专长伙伴。
- **第三章《世界之环》**：取得远洋线索、组建船队、完成跨海终极航程与商会挑战。
- 完成主线后可以继续自由经营。

原计划的基础事件仍包括：初到家园、首次买卖、许可证、首份配方、雇佣伙伴、首次修船、逆风、城市缺货、商会急单、海盗遭遇、古地图线索、最终远航。控制前期弹窗密度。

### 5.3 伙伴招募与个人事件

建议标准流程：发现NPC → 前置条件满足 → 接受任务/支付费用 → 任务完成 → 招募入队 → 信赖提升 → 追加个人事件。18名候选伙伴各对应一个核心招募事件，详见第4.3节。

事件奖励可包括资金、物资、声望、伙伴、配方、情报、航海线索、与其他势力的关系变化。所有结果通过相关系统正式结算，不允许绕过库存、品质和经济约束。

### 5.4 与黑雾探索联动

- 伙伴事件可以向玩家提供目的地、未知海岸或海怪方位的线索。
- **提供情报不等于真实航行探索**：未亲自驶过的未知海域，不因完成NPC对话而自动取得自动航行权限。
- 城市解锁产生的预定义多边形用于地图陆地揭雾；伙伴提供的线索与城市揭雾规则也不能错误打通未知海路。

### 5.5 与1021特殊商品/海怪构想的衔接（待定扩展）

此前提出：向指定商人累计出售100件特殊物品后，可解锁海怪线索，玩家在**各自的游戏世界**中寻找海怪。该事件可以与部分伙伴产生额外对话，但不强制招募指定伙伴。

仍需确定：物品是否可从公共市场购入、商人是否必须为同一人、海怪位置是否因玩家而异、奖励能否交易、是否可重复挑战。

## 6. 1023 决议与待定清单

### 已确定

1. 技能四大类12项以本文件第1章为唯一正式命名；**后勤**与**效率**替代旧名。
2. 三个地图场景共用永久探索黑雾；实时目标只在当前视野中显示。
3. 航行揭雾范围与船只视野相关，视野由船只大小和“视野”技能决定，参数外部配置。
4. 城市解锁揭开以陆地为主的**预定义多边形**；不能凭城市解锁自动获得海上航路通行资格。
5. 两个城市之间只有存在**完整已探索且可通航的海上路径**，才允许开通自动航线；可绕开未知海域。
6. 伙伴使用当前12项技能；18人作为本次设计名单，其中第18人采用虚构继承者设定，不把已逝历史人物直接带入1700年。
7. 事件系统保持独立、可配置、可插拔。

### 尚待决定

1. 黑雾内能否隐约看见大陆/海岸线轮廓。
2. 具体视野数值、揭雾倍率、云雾材质表现。
3. 自动航行是否在任何特殊情况下允许增加新的海域探索进度（当前默认不允许穿越黑雾）。
4. 伙伴姓名与1700年实际存在或年龄合理性的最终逐人史料校对；正式招募城市与数值平衡。
5. 伙伴技能成长曲线、叠加上限、事件奖励数值。
6. 1021公共市场及特殊商品海怪事件的详细经济与剧情规则。
