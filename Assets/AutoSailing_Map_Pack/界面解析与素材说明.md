# 自动航行地图：界面解析与素材说明

## 参考与制作范围

参考图为 729×406 像素。素材采用内置 image_gen 参照重绘，非原游戏资源提取；地形遮挡处、城市细节和船只未展示角度属于补绘。提示词见 prompts.json。原图保存在 08_reference。

## 界面结构

1. 顶部功能区：甲板为金色选中态，其余为黑灰底、细黄铜双边框。按用户命名提供“甲板、咨询、分配水手、功能”；截图实际采用繁体字形，其中第二项看起来为“資訊”。右侧另有“进港、出海”。按钮应以屏幕坐标固定，不随地图移动。
2. 势力标注区：“来岛家”“李家”是扁长深色牌匾，顶部功能区下面还有一个空牌匾。原截图另有“东亚”区域文字。势力牌匾和地域导航属于界面层。
3. 图纸与仪器：地图处于略带梯形透视的桌面画框内，上窄下宽。左上为天文／测角仪，右上为圆形黄铜刻度盘，左下为象限／六分仪类器械，右下是指南针、圆盘和旧纸。仪器名称仅为外观判断。下沿为黑底黄铜卷草边框。
4. 左下日期栏：“1月 4日”，数字和单位宜在实际游戏中单独渲染，当前同时提供整块图像与空牌底。
5. 地区导航：“去全世界”位于右上，“去东南亚”位于底部中央。本包提供独立按钮。

## 地图内容

- 地形：中国大陆在左侧，朝鲜半岛偏上，日本列岛在右侧，台湾在下方。山脉采用夸张立体起伏、亮山脊与暗背坡，平原绿褐渐变，内陆有沙黄色区域；海水从沿岸青绿浅海向外海深蓝过渡。海深是画面表现，不是真实水深数据。
- 城市：原图能辨认出约六组城楼／港口标记，包含中国宫殿城、城墙港、市镇宝塔、朝鲜式屋顶港口、日本塔寺港与城郭。此包给出六种风格重建，未将无法确认的地点强行标为真实城市。
- 船只：船体为俯视斜角小模型，米白帆、深褐木船身。按可复用素材需求扩展为方帆、三角帆、中式硬帆三类，每类八个航向，共 24 个独立 PNG。原图不能证明全部船型与方向，因此这些是风格补绘。
- 航线：普通线为较暗、半透明的白色细直线；选中线有不透明白色核心和浅色辉光。连线应存为港口节点关系，在运行时绘制；SVG 网络只提供截图布局近似示意。
- 洋流：成束弯曲白线，与港口直线不同；应沿曲线逐段流动并淡入淡出。静态截图无法提供真实速度，本包采用 2 秒循环、16 fps、32 帧，供调整。

## 文件与使用

| 文件夹 | 内容 |
|---|---|
| 01_map | 无城楼、船只、航线和 UI 的东亚地图 PNG |
| 02_frame | 中央透明的完整图纸边框与四角仪器组合 PNG；另附独立下边框装饰条 bottom_border_strip.png |
| 03_ui | 12 个独立透明控件 PNG 与原图集 |
| 04_cities | 6 个独立透明城楼 PNG 与原图集 |
| 05_ships | 3 类船 × 8 航向独立 PNG、各类原始图集 |
| 06_routes | 普通／高亮直线 PNG 与 SVG、港口选中圈、两种网络 SVG |
| 07_currents | 32 张透明动画帧、4096×1024 的 8×4 图集、循环 SVG |
| 08_reference | 用户原始截图 |

双击 preview.html 可离线浏览、切换船型和八方向、播放洋流。manifest.json 记录动画参数；atlas_regions.json 记录实际拆分区域和建议锚点。生成图集的间距不是严格等分，拆分按视觉边界调整。三角帆原图集的东西向排列与提示顺序相反，独立文件已按船头方向修正。

船只方向采用屏幕坐标：N 上、NE 右上、E 右、SE 右下、S 下、SW 左下、W 左、NW 左上。方向是手绘近似，桅杆保持竖立，各角度间帆形和细节会有差异。独立切图尺寸不完全相同，建议引擎统一画布并按船身水线校准锚点，避免旋转切换时跳动。

建议层级：地形 → 普通航线 → 高亮航线 → 洋流 → 港口选中圈 → 城市 → 船只 → 仪器边框 → 顶部控件与日期。原图对应的网络示意 SVG 为 729×406；应用于新地形时应重新绑定港口坐标。

## 核对与限制

透明素材保存为带 alpha 的 PNG，地图底图为不透明 PNG。边框为组合覆盖层，仪器没有各自独立拆出；可直接作为整屏装饰使用。图纸的倾斜感由边框和地形视角共同呈现，若需要可自由旋转的地图平面，应在引擎中另做透视投影。

这是一套参考重建素材，不保证原作逐像素一致；不是地理测绘地图，也不是精确三维模型渲染的八方向帧。生成的按钮装饰比原图更厚，地形与港口位置也有偏差，适合复刻原型和后续精修。
