Opening.mp4：开场与人物选择场景拆解

一、依据与交付边界
源视频：Screenshots/Opening.mp4，726×408，30 fps，约 6.53 秒。
时间段按关键帧估计：0–约 2.8 秒为开场；约 2.8–3.5 秒为叠化转场；其后为人物选择。不是逐帧标定的剪辑点。
reference 目录保存从视频直接提取的参考帧与每隔约 0.5 秒排列的联系表，按从左到右、从上到下阅读。
这次交付是场景拆解和制作规格；参考帧仍含遮挡、光效和压缩痕迹，不是已经去背、补全的独立游戏素材。
以下“观察”来自视频，“建议”是后续复刻方案，参数不代表原作内部实现。

二、开场：由后向前的图层

01 暗色环境底
观察：画面边缘为深蓝黑色，中心呈暖褐色；地球占据大部分画幅。
制作：纯色或渐变底，叠加独立暗角。不要把暗角烘焙进地球贴图。

02 古地图地球
观察：背景是带经纬线、大陆轮廓、古地图文字与帆船装饰的羊皮纸色球面，不是蓝色写实地球。片段还包含明显的构图缩放，不能把所有位移都解释为自转。
目标：按用户要求做慢速自转；中心稳定，地图在球面上连续移动。
建议实现：低细分球体 + 完整经纬展开的古地图贴图 + 柔和暖光。球体与标题独立；仅球体自转。首轮可试 0.5–1.5°/秒，完整一周约 4–12 分钟，再按观感调整。
轻量替代：球面投影着色器映射循环横移的地图纹理。直接平移一张截图容易露出边界，也无法还原球面曲率。
所需素材：完整世界地图贴图；可选纸张粗糙度贴图。建议主贴图 4096×2048。视频中未出现的地球背面和被标题遮挡的区域需要补绘。

03 主标题与罗盘徽章（已有）
观察：罗盘圆盘、金色“大航海时代”、红色 IV 和 HD-2D 形成中央主体；开场前段更大，随后收缩至较完整的构图。
制作：复用已有标题，先检查是否包含中央罗盘及 HD-2D、是否有足够分辨率。现有 generated/02_logo.png 出自左上角小标识重建，不能仅因文件名相同就认定适合放大成开场主标题。
建议：标题及徽章使用同一布局父节点做轻微缩小或镜头拉远效果。不要随地球旋转。标题自身不另行重做，缺少的部分再补齐。

04 remake
观察：小写“remake”，象牙白衬线文字，位于 HD-2D 下方，横向居中。
制作：独立文字节点，轻微深色阴影即可；不和标题烘焙成一张图，便于调间距。
以 2.5 秒帧为例，文字中心约在 (364, 330)，估计字号 18–20 像素。字体具体名称不能由视频确定。

05 Press Any Key to Start
观察：完整文字为“Press Any Key to Start”，位于 remake 下方，白色至淡金色衬线字；片段内可见明暗变化。
制作：独立文字节点，以透明度做柔和呼吸。建议周期 1.6–2.2 秒、透明度 0.3–1.0，参数是建议值。输入监听不受文字是否处于暗相位影响。
以 2.5 秒帧为例，文字中心约在 (364, 360)，估计字号 18–20 像素。
流程：首次按键或鼠标点击后锁定重复触发，播放转场并进入选人界面；不要把同一次输入传递成角色确认。

06 前景金色光带
观察：亮带从左侧进入，走弯曲轨迹穿过主标题，在右侧形成弧形/回卷后消散；亮带带有白金色核心、宽柔光晕及星点拖尾。不是一张均匀横移的半透明光斑。
拆为：A 发光核心带；B 更宽的柔光带；C 拖尾粒子；D 稀疏闪烁星点。
建议实现：沿曲线路径移动的头部 + 有限长度拖尾，使用加法混合。轨迹以屏幕归一化坐标定义，穿过标题中部，向右上抬升后回卷。初试单次 2.5–3 秒。
原视频只展示一轮，不能推断循环周期。若用于长时间停留菜单，建议每隔 8–12 秒重播一次，避免持续遮字。
所需素材：小型柔光点、星芒和渐变条，透明背景；路径、速度、长度与消散在游戏内控制。无需把整屏光效逐帧导出。

07 附加项
观察：底部还有很小的版权文字。它是视频参考的一部分；复刻项目应换成自己的署名或按实际授权处理，不直接视为必备美术层。
建议层序：底色 → 地球 → 环境暗角 → 徽章/主标题 → remake/开始提示 → 光带与粒子 → 全屏转场。
若暗角需要压暗所有前景，可另加很轻的最终暗角；不要影响提示文字可读性。

三、人物选择：由后向前的图层

01 木质桌面
观察：深棕木纹桌面构成下半部背景；上半部覆盖旧航海地图。画面近处有模糊航海器具，四周压暗。
制作：木桌作为最底层，地图独立覆盖，烛光和暗角独立。

02 倾斜世界地图
观察：地图纸张发黄、有磨损和褶皱，包含大陆线稿、经纬线与航海装饰；这是桌面透视，而非单纯把整张画面在屏幕上旋转 30°。
按用户目标：把“约 30°”作为初始机位/桌面夹角制作，再根据参考画面调透视。必须统一角度定义：镜头视线相对桌面平面夹角为 30°，等价于相对桌面法线为 60°。
优先建议：桌面、地图、卡片共享同一空间平面，相机倾斜观察。这样卡片透视、阴影和鼠标射线拾取一致。
轻量替代：预渲染桌面背景，卡片独立做四角透视；不要对整套 UI 统一 rotate(30deg)。
所需素材：无卡片、无鼠标、无高光的完整桌面底图；独立地图/纸张边缘；可选木纹贴图。被卡片覆盖的区域需要重建。

03 右上蜡烛
观察：右上角可见被画幅截断的烛台与亮色蜡烛区域，附近地图呈暖黄色照明。
建议拆分：烛台与蜡身静态层、火焰动画层、局部柔光层。固定机位可用透明图层；3D 桌面可用简单烛台模型。
火焰只做轻微形变与亮度波动；烛光建议 3–8% 的非周期性强度变化，避免全屏规则闪烁。推荐 6–12 帧火焰小序列或噪声驱动材质，均属制作建议。
蜡烛靠画面右上角定位，适配宽高比时保留其入画关系，不拉伸主体。

04 七张主角卡片
观察：上排 3 张、下排 4 张，均是独立金属装饰相框内的近景头像，边缘带卷饰；不只是无框人像矩形。
不凭低清画面确认角色姓名。临时以 P01–P07 标识，顺序为上排左到右，再下排左到右。
P01：深棕/黑短发人物，当前高光，面部部分被白色手形光标遮挡。
P02：黑发侧脸人物，右侧头饰/发饰。
P03：金色长发人物，暖色背景。
P04：浅棕短发人物，浅色衣领。
P05：橙棕短发人物，浅色衣领。
P06：银白长发人物。
P07：深色齐刘海人物，暖金色领口。
统一结构：落影 → 相框背板 → 裁切后的人像 → 装饰框 → 状态轮廓光；每张有独立点击区域。
人像建议每张至少 512×640；相框可复用一个主样式，但保留视频内轻微不同的旋转、尺度和透视。人像和相框分开，方便以后替换人物与做选中动画。
不要把手形光标画进 P01。遮住的脸部需要参考其他清晰素材或补绘，不属于直接提取可恢复的信息。

5.5 秒参考帧上的近似包围框（含装饰边框，单位像素）：
P01 [168, 98, 133, 132]；P02 [304, 100, 127, 129]；P03 [435, 101, 134, 130]。
P04 [88, 223, 141, 143]；P05 [229, 222, 135, 146]；P06 [369, 222, 137, 147]；P07 [509, 221, 151, 153]。
这些是人工估计的布局参考，不是精确抠图边界。镜头/卡片构图在片段内有变化，不能将此坐标用于所有帧。

05 hover / 焦点高光
观察：P01 的金黄色高光沿相框卷饰外边缘描绘，内部人像仍保持可辨；手形光标位于该卡片上。本片段未完整展示鼠标移入、移出及切换，不能据此确认状态机或动画时长。
推荐制作：从相框透明度生成轮廓遮罩或距离场；分成较窄亮边和较宽的柔光晕，不让人像区域整体发白。
以 726×408 输出为初调参考：亮边约 1–2 像素，外晕约 4–7 像素；按输出分辨率/DPI 缩放。预制光晕需要透明外扩留白，防止被贴图矩形边缘截断。
hover 进入 120–180 ms 渐亮，离开 150–220 ms 渐暗；可选轻微上浮或约 1.02 倍缩放，保留布局间距。以上均为实现建议。
将 hover、键盘/手柄焦点、已选择三种状态分别保存：鼠标离开时只撤销 hover，不撤销已选角色。选中可保持稳定亮边并增加小标记，避免仅靠亮度判断。
采用稳定的基础卡片区域进行命中检测，不随发光或缩放范围变化，以免边缘来回闪烁。斜放的 3D 卡片用桌面射线或卡片碰撞面拾取。
键盘/手柄焦点应复用同一套轮廓效果；上下排 3/4 张布局按空间最近邻切换，确认后再进入角色介绍或新游戏。
若使用后处理辉光，让它主要响应高光遮罩和火焰；避免纸张、脸部和整张相框一起过曝。

06 前景及界面附加层
观察：右下附近有虚化的航海仪器/金属弧形器具，上左角保留小标题标识，四角有明显暗部。
建议：虚化前景器具单独一层，控制其遮挡，不覆盖头像主体和关键点击区域；装饰层不拦截鼠标。
建议层序：木桌 → 地图 → 蜡烛静态物与照明 → 卡片阴影/卡片 → 高光 → 模糊前景器具 → 左上小标识 → 软件光标（如采用）→ 转场。
真正采用 3D 时以空间深度与透明材质规则处理遮挡，上述顺序仅表达合成关系。

四、建议素材清单与制作顺序
开场：古地图地球贴图 1；已有主标题 1；实时文字 2；柔光点/星芒/渐变条约 3；暗角可程序生成。
选人：木桌/地图背景 1 组；蜡烛静态图 1；火焰动画 1 组；独立头像 7；公共装饰框 1 组；框轮廓遮罩 1；前景器具 1；左上复用标识 1。
先确认现有标题是否适用于开场，再制作地球完整纹理与清洁桌面；随后制作七个人像、统一相框与状态遮罩；最后调光带、烛光、镜头缩放与转场。
不建议把 hover 光、文字或烛光烘焙进整张背景，否则更换人物、适配宽屏及做交互都会受限制。

五、验收重点
地球旋转没有接缝，标题保持独立；光带不持续遮住开始提示；文字缩放后仍清楚。
七张卡片均可独立命中；轮廓贴合装饰框且不裁边；光标不属于人物素材。
鼠标、键盘与手柄焦点状态一致；同一次开始输入不会顺带确认角色。
蜡烛和地图透视保持统一；不同宽高比下卡片与右上蜡烛不被意外裁掉。
低清视频不足以恢复精确字体、模型、贴图、角色遮挡部分和原作动效参数，后续重建应结合更高清参考。
