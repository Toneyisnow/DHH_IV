# 北欧城镇 3D 实景与透视验收

2026-11-08 用户补充：重新按参考港口图的位置布局制作北欧城镇，**所有建筑必须是真实 3D 模型，并符合透视效果**。

本次入口为 `Assets/Scenes/NordicHarborScene.unity`。主楼位于右前方，中央道路向远处延伸，左侧树木与市场形成街边层次，前景树木形成遮挡，后方配置民居与市政厅，两侧和远端为水域。右后方停靠高桅船，左右有泊位，修船区在右侧岸边水面。

四种建筑模型：HarborMerchantHouse、RedResidence、OchreResidence、TownHall。它们具有封闭墙体、屋顶体积、四面门窗、木饰、门阶、烟囱；主楼与市政厅附带实体阳台。场景实例化五栋建筑。建筑使用 MeshFilter/MeshRenderer，没有建筑 SpriteRenderer 或面向相机的整栋立面卡片。

相机为透视投影，非正交。保存正面、左右斜视、背面和绕行视角，结合模型几何范围、六方向法线、有向实体体积及投影比例检查，验证建筑不会在转动视角时变成一张薄片。

中央人物为已有欧洲角色静止帧，用于尺度参照；鸟群使用既有 2D 素材。该限制不影响建筑的 3D 验收，也不代表新 NPC 动作已经通过。

游戏可用模型、材质和预制体按类型存入 `Assets/Resources/*/Cities/Nordic/Harbor3D/`。源模型、Blender 工程、生成流程和验收资料统一在仓库根 `ArtSource/NordicHarbor3D/`。V2 素材库继续保留，新的北欧实景使用本套 3D 建筑，不把旧卡片视为已完成的 3D 建筑。

Play 操作：数字键 1 返回参考视角，2/3 查看左右侧；右键拖动旋转，滚轮缩放。独立预览不启动正式游戏 UI，也不改存档。
