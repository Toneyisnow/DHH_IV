# 城镇沿海元素 V2 与布局规范

用户细化需求，2026-11-08。适用于欧洲、北欧、地中海、非洲、亚洲、南美六种城市风格。本规范更新首版素材数量、道路拼接、岸线布局和飞鸟动画规则。

## 每地域素材清单

| 分类 | V2 规格 | 资源名称 |
|---|---|---|
| 道路 | 直路、转角、丁字口、十字口、尽头；另含广场整块。统一 4×4 米格，路口宽 2 米，可按 90° 旋转拼接。 | RoadStraight / RoadCorner / RoadTee / RoadCross / RoadEnd / RoadPlaza |
| 草坪 | 3 种平面：不规则圆形、宽椭圆形、拐角形；可随机选择、旋转、局部重叠组合草皮轮廓。 | GrassRound / GrassWide / GrassCorner |
| 房屋 | 2 种普通民居＋1 座较大的两层市政厅。HouseA 沿用首版，HouseB 为新轮廓，市政厅体量更大。 | HouseA / HouseB / TownHall |
| 树木 | 2 类树种，每类 3 种形态：细高、矮壮、带枯枝；共 6 种。棕榈类以枯黄下垂叶代替不符合植物形态的木质分枝。 | TreeA_Slim / TreeA_Short / TreeA_DeadBranches；TreeB 同样三种 |
| 市场 | 保留上一版造型和棚布微动。 | Market |
| 码头 | 固定栈桥＋两艘不同造型的停泊船。船只独立上下浮动并有极小摇摆；水平位置固定。 | Dock / BoatA / BoatB |
| 船坞 | 独立修船平台＋露出船肋骨、龙骨和部分船板的半成品船；另含组合预制体。 | RepairPlatform / HalfBuiltBoat / Shipyard |
| 飞鸟 | 同一类鸟的大小两种规格；每次 2–3 只，随机排列、随机方向，1–2 秒完整跨过屏幕。 | BirdLarge / BirdSmall / BirdFlock |
| 水域 | 缓慢波纹与岸边轻浪。 | Water |
| 布局样例 | 一套含陆地、岸线、水域及所有上述类型的组合。 | CoastalSample |

每地域共 30 个 V2 预制体（含组合和样例），六地域共 180 个。数量按可复用预制体计算，不等同于 180 张独立原画；道路/草坪形状为网格资产，鸟的两种尺寸共享同一种鸟的图像。

民居和市政厅的结构保持固定，随风摆动的是附带的独立屋檐挂饰；市场棚布与树冠沿用慢动。道路保留稀疏浮尘，路面和草坪自身不整体摆动。

## 两类树种

| 地域 | A 类 | B 类 |
|---|---|---|
| 欧洲 | 橡树 | 白桦 |
| 北欧 | 云杉 | 白桦 |
| 地中海 | 橄榄树 | 柏树 |
| 非洲 | 海枣树 | 金合欢 |
| 亚洲 | 椰子树 | 榕树 |
| 南美 | 热带开花阔叶树 | 王棕类 |

细高、矮壮、带枯枝是单独绘制的轮廓，不能只通过缩放同一张树图替代。树冠沿用根部固定的缓慢风动，树形高度在预制体中分别设置。

## 道路和草坪拼接

道路预制体中心按 4 米网格摆放，默认北为本地 +Z，东为 +X。接口掩码 N=1、E=2、S=4、W=8；旋转 90° 后同步轮转接口方向。相邻两格须互有对应接口，且中心相距 4 米。统一边缘坐标及宽度由网格生成器验证，地面材质以连续世界坐标采样，旋转路块不会改变接缝处纹理坐标。

草坪采用同地域纹理和三种不同边界的水平网格。组合时允许重叠，轻微错开高度避免重叠闪烁，避免让草坪覆盖道路。样例使用固定种子随机布置，便于重建和验收；正式关卡可手动调整布局。

## 沿海布局硬要求

**每座城市必须包含一部分可见水域。码头与船坞必须位于岸边的水上部分，并由栈桥或通路连接陆地。**

V2 样例约定：本地 Z=0 为岸线，Z≥0 是陆地，Z<0 是水域。码头入口落在岸线上，栈桥向水中延伸；两艘船靠泊在栈桥两侧，不能放在道路或草坪上。修船平台的主要占地位于水域，平台上的半成品船保持固定，不随停泊船一起浮动。

`RegionalCoastalPlacement` 在预制体中记录水域占地。构建验收检查整个标记矩形位于水域一侧，而不是只检查中心点。正式地图使用不同朝向或曲折岸线时，仍需按地图实际水域检测占地，并连接陆地寻路；该直岸样例不会自动改写现有全部城市布局。

## 飞鸟动画新规则

本规则取代首版的慢速往返飞行。每次随机生成 2–3 只，其中至少一大一小，采用同地域同类鸟的图片。路径从画面外一侧延伸到画面外另一侧，允许水平、竖直、斜向；编队有随机横向与纵向偏移。单次过屏总时间随机为 1–2 秒，较快振翅，飞出后隐藏；默认每 6 秒开始下一组。

路线按相机 Viewport 计算，并根据相机宽高比设置朝向和鸟的显示尺度。不能使用固定世界坐标的慢速小范围盘旋，不能让鸟停在屏幕中间。`BirdFlock.targetCamera` 可指定城镇专用相机；未指定时使用 MainCamera。城镇渲染到单独 RenderTexture 时应明确绑定城镇相机。

## 资源与使用

- 原图、生成提示词、修正原图、构建验收和预览：根目录 `ArtSource/RegionalCityElements/V2/`。
- 游戏 PNG：`Assets/Resources/Sprites/Cities/<Style>/V2/`。
- 网格、材质、预制体：对应 `Models`、`Materials`、`Prefabs/Cities/<Style>/V2/`。
- 索引：`Assets/Resources/Data/Presentation/Cities/RegionalElementsV2.json`。
- 预览场景：`Assets/Scenes/ArtPreview/RegionalCoastalElementsV2.unity`。默认欧洲，关闭当前样例后启用其他地域根物体。
- 资源调用示例：`Resources.Load<GameObject>("Prefabs/Cities/Asia/V2/CoastalSample")`。

图像由内置 image_gen 制作，完整提示词保存在 V2/Workflow/prompts.json。原始图集按实际输出尺寸分成 4×3 单元切片，不把请求尺寸当作实际尺寸。游戏使用固定视角 2.5D 卡片和实体地面/栈桥组合，树冠和棚布使用带固定点权重的网格风动。

隔离重建：`ArtSource/RegionalCityElements/Workflow/Build-Library.ps1 -Version2`；动态视频编码：`Encode-Review.ps1 -Version2`。原始 V1 素材和验收保留，用于追溯；新增布局应使用 V2 的 BirdFlock，避免混入旧的慢速 Bird 预制体。
