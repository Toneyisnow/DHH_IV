# 航海世家 / Maritime Legend

Windows 入口：`Builds/Windows/MaritimeLegend.exe`。首次构建完成后可直接双击，运行不需要 Unity 或网络。Unity 编辑器中打开本工程，场景 `Assets/Scenes/MainMenuScene.unity`，进入 Play。构建菜单：Maritime Legend / Build Windows。

## 开始航程

按任意键 → 新游戏 → 七个槽位中选空档 → 十个外观模板 → 修改外观、姓名、选择家园和休闲/经典模式。家园自带仓库及一个工坊，初始原料已在仓库中。人物技能严格只有规定的十二项；制造类别的配方、工艺、品质初始1级，另抽取三个不同产业专长，首个产业免费建坊。产业专长不是新增人物技能。

点击城市地点后人物自动走近进入；底部可直接进入各设施。先到产业园选中带 Lv1 的产业，开始一份原料足够的工单，等待约10秒领取。市场买入原料进入船舱，必须先在仓库卸货才能生产。数字数量在市场和仓库之间共享。

每城独立库存和压力。新档市场只存当地 Raw 原料的品质4、5：品质5为100件，品质4为其初始量的1%–20%。默认选择品质5；切换品质查看库存、买卖对应批次。大量买入涨价，大量卖出压价。买卖总价逐件计算，不能按原始报价锁整单。金币或容量不足，交易整体拒绝。

在海图选择其他城市，再点亲自出航。A/D转舵，W/S调速，Q/E调帆。船首方向用船体长轴表示。进入目的港半径后点击驶入目的港。缺补给可紧急返港，保留货物并最多收100金币。已实际航行的方向航线可安排非旗舰运输船。

外城到市政厅申请产业许可证；本城声望来自真实市场交易和商会委托。在伙伴页招募本港伙伴并安排当班；船型限制岗位。船坞购买新船后可设为旗舰，超载时先卸货。生产工坊可升级到5级增加订单槽。

第一章：买卖、生产、发现航线。第二章：三城产业园、当班伙伴、三单生产。第三章：三条航线，来自不同产地的品质2以上木板和布匹各一件，制造品质2以上旗舰航海仪和船帆，更换非小型帆船旗舰，培养一名信赖2级当班伙伴。满足条件后在任务页开始最终航程。目的港杭州；休闲检查补给和耐久，经典进入黑旗旗舰海战。完成后可继续经营。

海战：A/D转舵，S减速，空格发射侧舷炮。敌人必须在射程和侧舷角内；可以选择破坏船体或风帆。弹药耗尽或不利时可撤离。动画设置只控制炮火表现。

ESC 暂停。世界停止、生产仍按真实时间推进；设置中可另行暂停生产。总/音乐/音效音量分别控制。手动档和30秒自动档分开；读取时优先尝试自动档，损坏手动档可在档案页尝试备份。

存档目录：`%USERPROFILE%/AppData/LocalLow/MaritimeLegend/航海世家/Saves`。F12截图放在同级 `Screenshots` 文件夹。
