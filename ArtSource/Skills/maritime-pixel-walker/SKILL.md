# 航海角色像素行走图

先读 [动作与局部修正](references/animation.md)。涉及换装再读 [分层装备](references/layers.md)。导出与运行验证读 [Unity 验证](references/unity-validation.md)。DHH_IV 项目读 [项目基准与复盘](references/project-baseline.md)；其他项目不沿用角色专属坐标。

## 工作流程

1. 读取已确认的角色、服装、配饰方案，记录身份、体型、年代、惯用侧和组合。概念板不是透明装备层。
2. 保存当前验收版本和输入清单。先确定方向、帧序、落脚点、像素格和比例。DHH_IV 基准为64×96单格、8方向×(4行走+1停止)，并非其他项目硬性要求。
3. 先完成无帽、无披风、无挂饰的基础步态。沿肩—肘—手、髋—膝—脚检查第1/3帧的左右交换，再加装备。像素不同和动画计数器不能证明步态正确。
4. 原创位图和语义重绘使用 imagegen；帧裁切、调色、合层、锚点变换使用可复现导入/渲染管线。小改动只合成相关区域，不反复全图重画。
5. 明确图层、遮罩、挂点和各方向前后关系。先验收有代表性的组合，再扩展。交付说明实际选项数量，不能把未制作选项算作已支持。
6. 检查原尺寸、放大逐帧图、慢速原地循环和实际Unity移动。修改后同步最终图集与运行时，不能只替换运行时而继续交付旧图。
7. 保存输入、提示词、源图、导入参数、锚点/遮罩、图集和检查结果。明确原型、未独立分层和未核实历史细节。

## 动作约定

- 默认帧序：右腿前/左臂前；左腿跟进；左腿前/右臂前；右腿跟进；双脚着地停止。以角色自身左右命名。
- 前摆臂轻弯、后摆臂较直，两臂都要动。不能增加第三只手来补可见性。
- 腿保持自然窄步距，尤其斜下方向。明暗辅助识别，不能仅换颜色冒充换腿。
- 眼睛朝移动方向，嘴型稳定。固定眼嘴不等于冻结整头，头发应能摆动。停止不能突然缩眼。
- 正向下的眼、鼻、嘴共用最终像素母版；帽口贴合额头并遮住部分头发；披风逐帧跟随肩颈。三项都需独立穿戴对照，不能用组合枚举通过代替。
- 镜像交换解剖左右和装备侧。对称基础步态可镜像并偏移半周期，武器、肩宠、文字、非对称服装需单独处理。

用户具体设定优先。Character04修正坐标不能直接套给新角色。

跨角色实测、侧面肩宠遮脸和透明像素验证陷阱见 [Character05 实测反馈](references/character05-test.md)。
