# 第二阶段：原版渲染器的世界分区加载

## 使用

新建航程默认进入世界手动航海。已有东南亚区域存档仍可继续原航程，上方“世界手动航海”按钮可切换；切换前保存，原区域位置、跟随船位置和探索记录保留。旧 `world_v1` 试验存档另存位置快照后迁移到出发港安全水域，不把旧世界坐标误当作区域 UV。

主游戏入口仍为现有航海场景，控制、帆力、转向、跟随、镜头和界面沿用原系统。`StreamedWorldSailing.unity` 是独立验证场景，不读写玩家存档。独立验证程序位于 `ArtSource/RegionalSeasV2/UnityPreview/Build/StreamedWorldSailing.exe`。

## 数据与坐标

- 世界是矩形经纬度空间，32 单位/度，宽 11520、高 5120，纬度范围 −80° 至 +80°。使用等距经纬度展开；真正的等锥投影不具有矩形、等纬度直线与东西平移拼接这三个性质。
- `registration.json` 明确七幅区域插画的地理覆盖范围，东南亚范围由原有港口点作最小二乘配准。新大陆原图实际是加勒比海区域，没有把它拉伸成整个美洲。
- 插画比例并非测绘数据，采用可编辑的美术配准和重叠区平滑融合。七幅原地形决定覆盖区的起伏与植被；未覆盖的大陆用已有全球海岸数据补齐。不是七张矩形图片的硬拼接，也不声称达到测绘地理精度。
- 全球函数先决定高度/森林，再根据最终海陆形状生成通航距离。160×160 单位一块，128×128 单元，周围带共享采样边和法线 halo。全世界 2304 块，深海块不需要二进制资源。
- 东西资源键循环；显示坐标持续向前，船只存档经度规范化。南北墙只约束船只位移，水面仍向墙外延伸。

## 加载与画面

`StreamedSeaTerrain` 每次最多 4 个异步 IO/后台计算任务，每帧最多提交 1 个 Unity 网格与纹理，并使用 3 ms 提交检查预算（单个不可分割上传可能超出该预算）。Unity 对象创建、销毁、Resources 操作全部留在主线程。解析、地形网格和树石分布在后台生成。

船周围 620 单位预取、850 单位保留，旋转镜头不需要重新等待一个全新扇区；超出保留区 2 秒后卸载，驻留上限 196 块。船只附近及可见探索范围未就绪时暂停航行和航行计时；未知水域不能穿越，失败 3 秒后重试。释放 CPU 网格副本，并缓存树石变换，避免每帧重建数千个矩阵。

`StreamedSeaRuntime` 是原 `ManualSeaV2Runtime` 的坐标/资源适配层。轻量 Runtime Prefab 移除整幅区域地形及水深引用，保留原船舶、相机、天空、太阳、树石模型与材质。分区提供陆地网格与水深图，由原水面 Shader、云影、反射、泡沫及船舶接触效果绘制。新增 Shader 参数默认关闭；世界模式只启用大坐标噪声精度保护和探索纹理窗口偏移，原区域模式的公式与参数不变。

通航使用同一个 `CoastNavigation.MovePixels` 碰撞/慢速沿岸滑行实现。世界移动先换算到原 1672×941 像素空间，再换回世界单位；不会把南北速度错误变成与东西速度相等。点击目标、收放帆、调帆、停船、转向上限及跟随间距保留原行为。

现有 12 个东南亚港口继续使用原 3D 港口布局、地基贴地和材质，按需创建和卸载。全部 19 个游戏港口具备可通航出发点和入港判定；其他港口原本没有东南亚版 3D 布局，本阶段没有为它们新造城市美术。

## 复现与检查

1. `python ArtSource/StreamedSeasV2/build_atlas.py`
2. `python ArtSource/StreamedSeasV2/verify_atlas.py`
3. `python ArtSource/StreamedSeasV2/prepare_preview.py`
4. Unity 隔离项目执行 `MaritimeLegend.Editor.StreamedSeaBuilder.Build`；已有验证场景只需执行 `BuildSaved`。
5. Player 参数 `-streamReview <绝对 Review 目录> -logFile <日志路径>`。
6. 运行 `python ArtSource/StreamedSeasV2/publish.py` 发布验证后的 Prefab、场景及 GUID。
7. `MaritimeLegend/Tools/Run-SailingChecks.ps1` 检查旧航行行为和新世界单位换算。

证据在 `Review/atlas-checks.txt`、`Review/result.txt`、Player 日志及实景 PNG。检查涵盖共享高度/海岸/植被边及法线、双向日期线、两个极地墙的沿墙移动、未知资源阻挡、缺失资源重试、探索存档、近岸出发点与驻留上限。运行检查不是硬件帧率基准；没有把旧独立世界渲染器的截图算作新画面验收。
