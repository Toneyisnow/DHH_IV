# 验收边界

本文件区分已经实现的运行版本与原需求的完整验收线，不能把本版本视为所有条款均完成。

## 已有实现

Unity 6000.3.10f1 / Windows x64。标题、七档、两步参数建角、八港、八产业、50商品、33配方、独立动态市场、批次品质、工单三档计时、许可证、仓储、12名招募伙伴、4种船型、手动航海、方向航线解锁、可配置自动运输、三章任务、经典海战/休闲航行结局、通关后经营、手动/自动/备份存档。界面为1920×1080基准的Unity Canvas，后端可离屏渲染同一界面。音乐与音效为真实生成的AudioClip。

规则测试和后台UI事件回归的最终结果分别见 TestResults.txt 与 runtime-ui.log。运行截图由真实播放器的Canvas与Camera.Render输出，不是设计稿。UI回归调用真实按钮事件，但不等于人工鼠标/键盘全流程测试。经典海战有独立运行中的战斗胜利测试；完整经营流程通过确定性服务模拟验证。

## 尚未达到原要求的部分

- 人物是程序化二维组件，尚无高精度的3D展示立绘；八方向完整行走图集未制作。十套模板有脸型和配色差异，尚未达到参考人物画风的美术标准。
- 八城为原创简化像素港口，尚无要求的八方旅人级移轴效果、独特精细地标和完整NPC动画。
- 航海支持转舵、调速、调帆和补给，但地形碰撞、洋流、丰富天气、商船生态与随机海上遭遇尚不完整；普通海战通过演练和最终挑战进入。
- 船队拥有四船型、等级、运输占用和整备，尚未实现完整的可换舱室系统、士气和近战规则。
- 自动地图已有实时船队位置、港口、航线、缩放拖动及运输策略；尚未实现全部海域筛选、逐港市场详情、完整航段风险模型和所有快捷跳转。
- 伙伴有招募、当班、信赖和效果入口，但个人专属剧情、传奇专长分支与全部十二技能的丰富成长节点尚未完成。
- 事件含真实奖励和支援分支；持续剧情篇幅较短，不是长篇剧情作品。
- 配方计时、压力与品质等关键参数在配置中；部分航行、成长、战斗常数目前仍在Domain代码里，并未全部外置。
- 没有多人服务器、玩家订单簿、并发事务或跨玩家交易。
- 中文依赖Windows系统字体；尚未完成对所有Windows语言版本的离线字体覆盖验收。
- 尚未进行人工试听及人工完整两难度通关，不把后台测试称作已完成这些验收。

## 数据兼容

版本1存档使用JSON信封、SHA256校验、原子替换和.bak备份。高版本拒绝覆盖；当前只有版本1，不宣称已支持不存在的旧版迁移。客户端UTC异常只做上限和记录，单机存档不具有服务端反作弊能力。
