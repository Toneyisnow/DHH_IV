# 东南亚十二港口：实体模型与出海位置

范围：马六甲、马尼拉、巴达维亚、巨港、泗水、文莱、望加锡、万鸦老、德尔纳特、安汶、嘉定、大城。

## 当前实现

航海地图使用有体积的 3D 网格，包含屋顶、瓦条、屋檐、四面墙、门窗、木梁、码头与桩基；不再使用朝向镜头的城市四边形。整体范围沿用原城市图案的宽度与高度参数，新增纵深。各建筑在城市范围内搜索相对平缓、互不重叠的位置，每处地基和码头桩脚分别采样海岸高度场，延伸到山坡或水下地面。建筑保持竖直，不把整栋房子扭曲到坡面上。地形遮挡、光照、昼夜色调与已探索区域共同作用；悬停通过实际网格命中检测。

这是根据前版图案的建筑风格重新制作的低多边形建筑群，不是单图自动还原的历史建筑测绘模型。城内场景目前复用马六甲的公共城市场景布局；独立 3D 建模用于航海地图。

## 源文件与运行资产

- `Models3D/*.json`：可编辑的建筑布局、配色与屋顶层数。
- `Models3D/generate_layouts.py`：十二城布局生成入口。
- `Models3D/*.obj` 和 `*.mtl`：可在 Blender 等软件中编辑的实体网格与材质。
- `Generated/`、`generation-prompts.json`：前版 2.5D 参考图及内置 image_gen 提示词，保留但不再作为航海城市显示面片。
- 游戏资产：`MaritimeLegend/Assets/Resources/Models/ManualSailing/Ports3D/`。
- 模型网格生成器：`MaritimeLegend/Assets/Sailing/CoastalCityMesh.cs`。
- Unity 导出入口：`CoastalCityModelExport.Run`，构建时重新按当前地形生成模型并保存 OBJ 和游戏网格。

## 出生与迁移

原问题是 `ManualSeaPresentation` 为域外城市保留了硬编码的南海中央入口；旧档还会继续保留这个出生点。现已删除此兜底。

新人物从十二个东南亚城市中随机确定家园。旧档首次读取时，如果当前位置不在东南亚，则随机分配东南亚城市；只执行一次并保存标记，保留原家园资产、人物身份、资金、货物、产业与任务进度。已经处于有效东南亚港口的角色保留当前位置。旧的海中央入口会重新定位。

城市 ID 保留原 0–7，新十一城追加为 8–18；新增城市使用基本港口数据，未设计独立任务与独有产业平衡。旧档以追加方式补齐城市状态，不覆盖现有城市仓库。

每次出海按实际城市 ID 查找 `Environment/SoutheastAsiaV2/ports.json` 中的近岸安全出生点；初始镜头 10、最小 8。正常继续有效航海存档不重置船位或镜头。全部港口出生点均位于同一连通安全海域。

## 验证

构建入口 `SailingV2Integration.Build` 执行城市结构、配置、航海与海域连通检查，并导出十二城实体模型。`-portsCompassSmoke` 检查旧档迁移、随机范围、保存后城市不变、十二城实际出海位置、镜头、指南针、三维悬停、探索遮挡、绕行时模型保持固定，以及十二城城内场景身份。

构建与实机日志在 `Review/build3d.log` 和 `Review/runtime3d.log`；预览入口为 `preview3d.html`。
