# Unity 验证

DHH_IV源图、提示词、生成流程、遮罩、审阅在仓库根ArtSource/；游戏图集在Assets/Resources/Sprites/Characters/CharacterXX/，Prefab按类型单独存放。不要在Unity内部另建ArtSource。
当前64×96单格、8×5图集、Point、无压缩无mipmap、统一PPU/脚底pivot。新比例可调整。斜向速度归一化，松键当前朝向独立停止；换装不重置位置和方向。

检查：
1. 方向索引、4帧循环、停止、连续转向、斜向速度。
2. 所有声明配色/装备可选择，层引用完整，禁用后无残留。
3. 最终图集与运行时一致，不能拿旧图当最终。
4. 实际渲染关键帧：肢体连接、交替、步距、前手遮挡、停止落脚。
5. 头锚稳定；眼嘴区域按头位一致；头发仍有变化。透明RGB边缘膨胀不算可见差异。
6. 小修改与已验收版比对，相关范围以外不变或说明必要变化。
7. 装备不裁断，头顶无相邻行鞋底。
预览提供方向、原地循环、逐帧、低速、缩放、换装。非空sprite/像素不同/构建成功不能称为解剖已通过。
用户编辑器已开时不抢构建锁、不关闭编辑器。用已有隔离测试项目构建，再同步授权文件。只关闭本任务旧预览进程。独立新场景/对象，除非要求集成主游戏。
保存真实检查输出、审阅图、输入清单与SHA256快照，标注原型限制。
