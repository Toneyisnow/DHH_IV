# 素材来源与许可记录

1. `Resources/Art/town.png`：用户提供的 `Assets/Town_Scene_Pack/generated/scene_clean.png`。原包 scene_config.json 标注 reference-based AI reconstructions，非原游戏无损提取。作者/授权主体未在清单给出，不能自行声称CC0或商业再分发已获许可。
2. `portrait.png`：用户提供 `Assets/Screenshot_Reconstruction/generated/04_portrait.png`。用作故事人物示意。来源包未包含独立商业授权文本。
3. `walk.png`：用户提供同包 `09_walk_sheet.png`，保留参考，目前参数角色由程序绘制。
4. `globe.png`、`map.png`：用户提供 `Opening_素材/01_开场/01_globe.png` 和 `02_world_map_texture.png`。来源为用户项目资源，许可状态同上。
5. 八城像素港口由PixelPorts生成；当前像素人物组件、船只形状、边框由本项目代码原创绘制，无外部资源包依赖。
6. 三首循环背景音乐和11种提示音由 `GameAudio` 合成，无采样第三方录音。
7. 中文字体通过 Windows 已安装的 Microsoft YaHei / SimHei 动态加载，本构建不打包或再分发字体文件。Windows缺少这些系统字体时尚未有完整中文字体替代包。
8. 引擎和Unity包沿用用户新建工程与Unity许可证。此记录不替代原资源版权人的授权。

本次没有下载外部音画素材，没有把参考重建图误标为CC0。公开商业发行前，需确认用户提供参考图的再分发授权，或整体替换为获得明确许可的资源。
