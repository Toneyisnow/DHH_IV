## 文件与层结构
每名角色在 `../CharacterXX/`：
- `Review168/`：40 个透明帧与 walk-sheet.png；8 方向 ×（4 行走 + 1 独立停止）。每格168×168，图集840×1344，行顺序 N NE E SE S SW W NW，脚底pivot(84,10)，PPU64，Point，无压缩。
- `Wardrobe/equipment-generated.png`：原始装备方向板，三行分别头饰/披风/饰品；每行八视角。
- `Wardrobe/Layers/`：hat-back、cape-back、accessory-back、body-hat、cape-front、accessory-front、hat-front。body-hat 仅在戴帽时替换基础身体，用于隐藏帽内高髻/头发；脱帽恢复原发型。
- `Wardrobe/anchors.json`：每方向每帧帽口、肩颈、腰侧挂点与披风领口源坐标。
- `Wardrobe/variant-review.png` 与单件 review 图仅作审阅，不作为运行时全组合资源加载。
- 基础与装备的 Loop/、walk-review-slow.gif：八方向慢速循环。

游戏就绪资源复制到 `Assets/Resources/Sprites/Characters/CharacterXX/CartoonWalk/` 与 `ModularWalk/`。

## 如何更新而不产生组合爆炸
1. 修改基础动作时，更新 Review168 对应帧和挂点；装备层按这些挂点重新导出。
2. 换头饰只增加头饰方向源与帽内头发遮罩；换披风只增加前后披风层；换饰品只增加对应前后层。
3. 运行时共享同一方向、帧号与脚底pivot，按槽位显示图层。不要为每个 H×M×A 组合生成全身图集。
4. 更新后检查单件、混搭、后向披风、帽口接触、前手遮挡腰部饰品，再同步资源并运行 Unity 测试。

装备本次采用八视角单品源，随每帧挂点位移；披风下摆有轻微相位偏移，不是布料物理模拟。

## 可复现流程
- `../pack-new-five.cjs`：分格、透明边缘清理、统一尺度、基础对称肢体半周期交换、保留身份/中部非对称衣装、正面共用五官母版。
- `../build-new-wardrobe.cjs`：方向装备切片、帽内头发遮罩、领口定位、方向前后遮挡、挂点和预览。
- `../review-new-five.cjs`：逐帧重复检查、图集规格、哈希、自包含交互检查页与总览。
- prompts.json：生成与重做提示记录；原始 v1/v2 生成图保留，最终以 Review168 为准。
- asset-checks.json：导出规格与哈希；这些技术检查不代替人工动作审阅。
